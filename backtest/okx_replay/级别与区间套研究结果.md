# 按原作者方法：级别 + 区间套（OKX，100 个加密币，约 2 年 30 分钟数据）

## 实现了哪些原文要点
| 原文要点 | 这里怎么做 |
|---|---|
| 背驰段 a+A+b+B+c | 大级别“正在形成的一笔”离开最后中枢并创新低/高，其同向 MACD 面积小于进入段 b 的 0.9 倍 |
| 黄白线回拉 0 轴 | 可选条件：中枢 B 期间 MACD 快线穿过 0 轴 |
| 趋势背驰与盘整背驰 | 两个 GG/DD 不重叠的中枢算趋势背驰（T1），否则算盘整背驰（T1P） |
| 第三类买卖点 | 离开中枢后，形成中的回抽笔没有回到中枢核心（T3）；收盘回到中枢内即认错 |
| 区间套 | 大级别候选成立期间，小级别确认同方向的 1买 / 盘背1买 才入场，止损放在小级别转折点外 0.5 ATR |
| 同级别分解 | 出场 E1：大级别出现反向买卖点才走 |
| 出场也用区间套 | 出场 E2：小级别出现反向背驰（1卖 / 盘背1卖）就走 |
| 走势终完美 | 出场 E3：回到大级别中枢边界后，止损移到成本并用 3 倍 ATR 移动止损（3类改为盈利 1R 后启动） |

- 两组级别：4h 大级别 + 30m 入场；1d 大级别 + 4h 入场。
- 所有判断只用当时已经知道的数据。成本按往返 0.2% 计算。
- 事先定好的挑选规则：只用第一年的数据，选扣成本后每笔平均最高、且至少 100 笔的组合；第二年只检验这一个。

## 结果
**4h + 30m**：两年共 581 笔，88 个币。
- 第一年所有组合扣成本后都为负。
- 规则选中“3类 + E3”，第一年 −0.036R，第二年 +0.049R（95% 区间 ±0.353R），与 0 没有区别。
- 第二年多数组合看起来为正，但几乎全部来自一笔交易：XPL，2026-03-29 入场，止损 0.44%，一周内涨了 93%，
  这一笔 +168R。去掉最好的 5 笔后，第二年每笔为 −0.15R 到 −0.17R。
- 胜率 13%～22%，中位数单笔约 −1R：大部分时候止损，偶尔一笔大赚。
- 只做“趋势背驰 1类”：两年都为负（第二年 E1 为 −0.53R）。
- 加“MACD 回拉 0 轴”条件：没有稳定改善。

**1d + 4h**：两年只有 64 笔，样本太少。第一年为正的组合，第二年全部为负。

## 结论
按原作者方法做成固定规则后，在这批数据上**也没有稳定的优势**：
- 收益形态是“多数小亏 + 偶尔一笔特别大的盈利”。这样的结果完全取决于能不能碰上那几笔大行情，
  两年的数据不足以判断长期能不能赚钱。
- 如果实盘做这种策略，一旦错过那几笔大行情，就是持续小额亏损。

## 局限（和原作者的实际做法仍有差距）
- 原文里每个级别的走势由下一级别的走势构成（线段、递归中枢）。这里用“4h 的笔”近似大级别走势，没有做严格的逐级递归。
- 原文的区间套可以套三层以上（日线 → 30 分钟 → 5 分钟），这里只套了两层。
- 原作者强调的主观部分没有纳入：分批建仓与减仓、中枢震荡里做差价、结合基本面和板块。
