## 一、买点

### 一买
- 定义：该级别的背驰点。"第一类买卖点，就是该级别的背驰点，这足以应付最大多数的情况，但有一种情况是不可以的，就是……小级别转大级别的情况。"[53]
- 判断：绿柱子缩短而价格继续创新低。[14]

### 二买（和方案二关系最大）
- **买点定律**："大级别的第二类买点由次一级别相应走势的第一类买点构成。"[14]
  → 方案二的"二买 = 30 分钟回抽里 5 分钟出现一买"**符合原文**。
- **定义**："第一买点出现后的第二段次级别走势低点就构成第二类买点……其后必然有第三段向上的次级别走势出现，因此该买点也是绝对安全的。"[21]
- **二买可以比一买低**："次级别向下后一次级别向上，如果不创新高或盘整背驰，都构成第二类卖点，而买点的情况反过来就是了。"[53]
  → 也就是说，二买只要"不创新低"**或者**"盘整背驰"就算。**方案二要求"不破一买低点"，比原文严，漏掉了"破低但盘整背驰"的二买。**
- **二买的位置决定强弱**："中枢下出现的，其后的力度就值得怀疑了，出现扩张性中枢的可能性极大；在中枢中出现的，中枢扩张与新生的机会对半；在中枢上出现，中枢新生的机会就很大了。"[21]
  → **方案二没有区分二买的位置**。可以测"只做中枢上方的二买"。
  （注：实战资料说"中枢下沿做多有优势"，和原文这条相反，以原文为准。）
- **MACD 形态**："用 MACD 黄白线第一次上 0 轴然后横在 0 轴上形成第二类买点的判断"[51]；"形成第二类买点，同时黄白线在 0 轴附近横盘"[25]。
  → **方案二没有这个条件**，可以测。
- **一买和二买哪个好**："在有第一类买卖点的情况下，第一类买卖点是最佳的，第二类只是一个补充；但在小级别转大级别的情况下，第二类买卖点就是最佳的。"[53]
- **散户**："一般可以在第二类买点出现后才考虑介入，或者更干脆的，是第三类买点出现再介入。"[55]
- **二买三买重合**：一买后次级别走势直接上破前面下跌的最后一个中枢，回抽不触及中枢 → 二买与三买重合，"最好的补进机会"。[21]

### 类二买
- 原文只出现两次，意思和实战说的不一样："在大级别里，如果不出现新低，但可以构成类似第二类买点的买点，在 MACD 上，显示出类似背驰时的表现，黄白线回拉 0 轴上下，而后一柱子面积小于前一柱子的。"[27]
- 实战的"类二买"（二买之后中枢震荡里的买点，可以有多个）是后来的人整理出来的说法。**方案二的类二买加仓来自实战，不是原文。**

### 三买
- 定理："一个次级别走势类型向上离开中枢，然后以一个次级别走势类型回试，其低点不跌破 ZG，则构成第三类买点。"[20]
- "在牛市里，第三类买点的爆发力是最强的。"[33]

## 二、背驰怎么判断
- 前提："A、B、C 段在一个大的趋势里……B 是这个大趋势的另一个中枢，这个中枢一般会把 MACD 的黄白线回拉到 0 轴附近。"[24]
- "C 段的走势类型完成时对应的 MACD 柱子面积（向上看红柱子，向下看绿柱子）比 A 段对应的面积要小，这时候就构成标准的背驰。"[24]
- "别以为看到绿柱子就知道背驰，那只是辅助手段，首先要搞清楚趋势。"[16]
- 面积估算："柱子伸长的力度变慢时，把已经出现的面积乘 2，就可以当成是该段的面积。"[24]
- C 段上破中枢但面积小于 A 段："先出来，其后……如果回跌不重新跌回，就在次级别的第一类买点回补，刚好这反而构成该级别的第三类买点。"[24]
→ 方案二的背驰判断（面积小于进入段、黄白线回抽 0 轴）**符合原文**；"面积小于 90%"的门槛是我定的。

## 三、区间套
- "5 分钟背驰段的 1 分钟背驰段的次级别的背驰这样的三重背驰……区间套定理的精确定位。"[28]
- "你不是大级别一进入背驰段就操作的，而是要用区间套进行依次定位，这样，如果突然有意外发生，实际上你极大可能并没有进入操作。"[30]
- "5 分钟的背驰是否要走，你要根据当时 30 分钟、日线的情况来看，如果大级别在主升段，就算走了也要买回来。"[32]
→ 方案二的"日线 → 30 分钟 → 5 分钟"逐级确认**符合原文**；四层（加 1 分钟）正在测。

## 四、卖点、短差
- **短差程序**："大级别买点介入的，在次级别第一类卖点出现时，可以先减仓，其后在次级别第一类买点出现时回补。"[14]
- **小背驰-大转折定理**："小级别顶背驰引发大级别向下的必要条件是该级别走势的最后一个次级别中枢出现第三类卖点。"[44]
  → 小级别出现一卖，**不一定**是大级别转折；真正要走的信号是**三卖**。
- "如果从底背驰开始的次级别回拉不能重新回到中枢里，那就意味着第三类卖点出现，必须走。"[33]
- "日线上在上涨的中段刚开始的时候……这时候 5 分钟即使出现背驰，其下跌力度显然有限，所以只能打点短差，甚至可以不管。"[24]
- "前面出现'上涨+盘整+上涨'走势的，一旦第二段升势出现第一类卖点，一定要走。"[16]
→ 方案二"一卖卖一半、三卖清仓"大体符合短差程序；但原文强调**大级别强的时候，小级别一卖可以不管**，方案二没有区分。

## 五、原文的"机械化操作模式"（第 49 课，方案二没有用）
- "该模式的关键只参与确定操作级别的盘整与上涨，对盘整用中枢震荡方法处理……在中枢第三类买点后持股直到新中枢出现继续中枢震荡操作，中途不参与短差。"
- "在围绕中枢差价时，在中枢上方仓位减少，在中枢下方仓位增加……一旦出现第三类卖点，就不能回补了。"
- "中枢向上移动时，就应该满仓，这才是最正确的仓位。"
- "还有一种更激进的操作方法，就是不断换股，也就是不参与中枢震荡，**只在第三类买点买入，一旦形成新中枢就退出**。"
→ 这是原文里**写得最像规则**的两套操作方法，可以直接写成程序测试。

## 六、同级别分解的操作程式（第 38 课，之前的测试写得太简单）
- "以 30 分钟级别为操作标准的……只选择其中的上涨和盘整类型，而避开所有下跌类型。"
- 机械程式："从一个下跌背驰开始……必然首先出现向上的第一段走势类型，根据其内部结构可以判断其背驰或盘整背驰结束点，先卖出，然后必然有向下的第二段，这里有两种情况：1、不跌破第一段低点，重新买入；2、跌破第一段低点，如果与第一段前的向下段形成盘整背驰，也重新买入，否则继续观望，直到出现新的下跌背驰。"
→ 之前测试的"同级别分解"只是跟着线段方向走，**不是这个程式**，需要按原文重写再测。

## 七、仓位与资金管理（和方案二有冲突）
- "本 ID 的仓位是一直不变的，最开始多少就是多少……卖点的时候变少，买点的时候又回复原来的数量，但**绝对不加仓，一开始就买够**。"[26]
- "成本为 0 前，只补进相同的数量，仓位不增加。"[31]
- "一个中线的仓位，至少应该在一个日线级别的买点介入。"[31]
- "第二类买点是可以的，但一般都采取比较温柔的办法，慢慢来。"[22]
- 大资金："一个至少从第二类买点开始利用部分前戏的介入是必须的……有利用前戏的震荡降低成本、增加筹码的必要。"[55]
- "资金管理……比任何的技术都重要。"[31]
→ **原文主张一次买够、不加仓，靠卖点减、买点回补来做**；"一买轻、二买加、三买重"是实战的说法。**方案二的类二买加仓来自实战，和原文第 26、31 课不一致。**

## 八、止损、认错
- "一旦你的操作，陷入一种与当下走势相反的状态……唯一正确的选择就是离开。"[34]
- "一旦出现'早泄'现象，必须马上退出。"[9]
- 原文没有给具体的止损价位规则；"跌破一买低点止损"来自走势定义（跌破说明一买判断错了）和实战资料。

## 九、选股、板块
- "选股票一定要按技术来找，找有第三类买点的，或至少是刚从第三类买点起来的。"[33]
- "日线上的，如果实在找不到，就找 30 分钟上的。"[33]
- "把一些有潜力的板块……弄个 100、几十只的，然后每天在这些股票里选买点。"[33]
- 板块强弱指标、轮动。[106]
→ 方案二按成交额选币、用大盘宽度，是我定的替代，原文的选股是"找三买"。

## 十、实战资料补充（非原文）
- 一买轻仓试探，二买加仓确认，三买重仓追击。
- 二买的把握：30 分钟盘整背驰，或 5 分钟中枢底背离。
- 类二买：一般比二买低点略高；在二买价位附近出现次级别背驰或底分型更可靠；可以有多个。
- 卖点：一卖减仓，二卖继续减，三卖清仓。
- 区间套的三种情况：正常（最小级别背驰时操作）、小转大（等次级别回抽确认）、反复背离（只观察）。
- 二买止损：跌破一买最低点离场。

## 十二、建议接下来测的
1. **二买放宽到原文定义**：破一买低点但盘整背驰也算二买。
2. **只做中枢上方的二买**（原文说最强）。
3. **二买加 MACD 条件**：黄白线第一次上 0 轴后在 0 轴附近横住。
4. **按原文一次买够、不加仓**，对比现在的分批加仓。
5. **大级别强时不理会小级别一卖**，只在三卖、大级别卖点离场。
6. **原文机械化操作模式 A**：只在三买买入，新中枢形成就退出（第 49 课"激进"版）。
7. **原文机械化操作模式 B**：三买买入持有，中枢上方减仓、下方回补，三卖离场（第 49 课）。
8. **按第 38 课程式重写同级别分解**。

每一项都同时用两批数据测：原来的 40 个币，加上没测过的 30 个新币。两批都变好的才算有效。
