# 严格递归 + 三层区间套 + 主观规则：全参数测试结果

数据：OKX 成交额最大的 40 个加密币，约 2 年 5 分钟 K 线（2024-09 至 2026-09）。
前一年用来挑参数，后一年用来检验。成本按往返 0.2% 计算。

## 一、这轮顺带修好的缠论引擎问题（已提交到系统）
1. **特征序列包含处理的错误**：新元素创出线段方向的新极值时，会被并进左边的元素，
   导致真正的顶/底分型永远凑不齐，线段被拖得很长（BTC 30 分钟上有一段长达 327 笔）。
   原文规则是“分型的第一、第二元素之间不做包含处理”，已按此修正，并加了真实行情片段做回归测试。
2. **速度提升 3～4 倍，结果完全不变**：两年 5 分钟 K 线单次分析从 132 秒降到 34 秒；
   改动前后的输出在真实数据上逐字节比对完全一致。实盘扫描同样受益。
3. **新增可选的“宽松线段”模式**（默认关闭，实盘行为不变）：
   - 严格模式：线段端点必须是段内极值，否则线段不能结束。在 5 分钟上平均 52 笔一段，太长。
   - 宽松模式：出现特征序列分型就结束线段，与开源项目 chan.py 的做法一致，平均 6.3 笔一段。
   - 大级别在宽松模式下有 287 个单元、36 个中枢，才够测试三层区间套。

## 二、测试了什么（共 91,188 个参数组合）
| 类别 | 参数 | 取值 |
|---|---|---|
| 结构 | 线段模式 | 严格 / 宽松 |
| | 笔 | 老笔 / 新笔 |
| | 背驰面积 | 同向柱 / 绝对值 |
| | 背驰力度阈值 | 0.7 / 0.8 / 0.9 |
| 入场（区间套） | 层数 | 三层 / 大+小 / 中+小 |
| | 大级别点位 | 只趋势背驰 / 含盘整背驰 / 再加三类 |
| | 小级别 | 只趋势背驰 / 含盘整背驰 |
| | MACD 回拉 0 轴 | 要求 / 不要求 |
| 止损 | 转折点外缓冲 | 0.25 / 0.5 / 1.0 ATR |
| 出场 | 同级别分解（中级别卖点） / 大级别卖点 / 走势终完美 + 移动止损 | |
| 主观规则 | 分批建仓（1买 1/3，2买、3买各加 1/3） / 中枢做差价 / 两者都用 | |
| 选币 | 不选 / 相对强度前 50% / 前 30% | |
| 市场宽度 | 不看 / >50% / >60% | |
| 方向 | 多空 / 只做多 | |

严格线段只保留了一组结构参数（老笔、同向、0.9）做对照：严格模式下大级别在两年里只有约 2 个中枢，其余取值没有意义。

主观部分的规则化，依据的是原文要点，以下是意译：
- **分批建仓**：1买只是底部的第一个提示，先轻仓；2买、3买确认后再加。
- **中枢震荡做差价**：持仓期间，在次级别卖点减掉一部分，在次级别买点买回，降低成本。
- **选强势品种**：资金推动走势，优先做走得最强的。加密市场用 30 日相对强度和市场宽度代替板块与基本面。

## 三、结果
1. **事先定好的规则选中的组合失败**：
   - 组合：宽松线段 / 老笔 / 绝对值 / 0.8、中级别 + 小级别、强势前 30%、只做多、止损 0.25 ATR、中级别卖点出场；
   - 第一年每笔 +6.38R（60 笔），第二年 **−0.32R**，第二年中位数 −1.15R。
2. **第一年最好的 20 个组合在第二年只有 4 个为正**；最好的 100 个里有 22 个为正。
3. **去掉每个组合最好的 5 笔之后**：
   - 21,972 个组合里（MACD 回 0 轴对结果没有影响，已合并），**两年都为正的有 0 个**；第一年为正的比例是 0%。
   - 所有组合的中位数单笔都是亏损。
   - 看上去赚钱的组合，全部靠 5 笔以内的大赚交易撑着。
4. **相对好一些的做法**（各参数取值分组后比较中位数，两年方向一致，但仍然全部为负）：
   - 分批建仓：约 −0.13R，不分批约 −0.34R；
   - 止损宽一点（1.0 ATR）；
   - 只做强势币（前 30%）。
5. **没有作用的**：
   - MACD 回拉 0 轴：5 分钟上一个中枢持续几小时到几天，期间 MACD 几乎总会穿过 0 轴，这个条件等于没设。
   - 严格线段：比宽松线段更差（第二年 −0.32R，宽松 −0.18～−0.28R）。

## 四、结论
- 按原作者的方法做到严格递归、三层区间套，再加上分批、做差价、选强势，**在这 40 个币、2 年的数据上没有稳定的优势**。
- 这类策略的结果形态固定是：多数单子止损，偶尔一笔大行情赚几十 R。
  第一年挑出来最好看的参数，只是恰好碰上了那几笔大行情。
- 分批建仓确实能减少亏损（首笔只有 1/3 仓位），这是唯一在两年都一致改善的主观规则，但也没能让结果转正。

## 五、局限
- 只有 2 年数据、40 个币，而且以加密市场为主；A 股、日线、周线级别没有测试。
- 真正的主观部分（判断大盘环境、题材、消息、盘口）无法写成固定规则。
- 三层区间套在两年里很少同时出现（每个币约 2～10 次），样本偏小。
