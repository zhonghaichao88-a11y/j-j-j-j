# 原文全套（第三版）+ 主观部分 + 资金费率/持仓量

脚本：`yuanwen3.py`（结构规则）、`yw3_eval.py`（主观筛选与组合）、`fetch_fund_oi.py`（资金数据）。完整明细 `yuanwen3_summary.csv`。
单位：每用 1R 风险赚多少 R，扣往返 0.2% 成本。

## 这一版的规则改动（按原文）
1. 二买/类二买：区间套早进场（1买后本级别走出一段反弹，回抽段里次级别 1买、不破 1买低点）。
2. 严格版只认趋势背驰（本级别两个不重叠中枢，次级别也必须是趋势背驰 1买）；"含盘背"版对照。
3. 背驰 = MACD 面积 < 90% + 黄白线回抽 0 轴 + 离开段斜率小于进入段（严格版全部要求）。
4. （撤回）次级别改用 5m 线段：实测 5m 线段与 15m 线段大小相近，不是次级别；按原文递归，仍用同一周期的笔作次级别。
5. 中枢延伸到 9 段视为升级：本级别 1买/1卖 必须大级别同时背驰。中枢扩展不算趋势。
6. 小转大：本级别没有背驰，次级别 1买 低点成为本级别新一段起点 → 当作 1买低点，之后按 2买/3买 介入；卖出方向同理。
7. 同级别分解：单独一套（线段确认向上做多、向下离场/做空，线段起点保护止损）。

## 主观部分（原文没有给规则，以下是替代）
- 大盘环境：市场宽度（日线在 EMA50 上方的币占比）≥ 50%（做空取反）。
- 板块/强势：30 日相对强度前 50%。
- 资金轮动：组合最多同时 5 组，同时出现优先最强。
- 资金费率（接口只有 2026-06-29 以后）：做多时费率 ≤ 0.01% 算不拥挤（做空取反）。
- 持仓量：入场前 3 天日线持仓量（币本位）增加 = 资金流入。
- 做不了的："当下"完全分类里作者的临场取舍、消息/基本面（无历史数据）、盘口（交易所不提供历史）。

## 结论
- 按原文把结构规则补全后，仍然没有一组在五段时间里都赚，去掉最好的 5 笔几乎全部为负。
- 主观替代里只有"大盘宽度"比较一致地有帮助（多数时间段变好），与之前方案一的测试一致；但也没有让结果稳定转正。
- 相对强度、持仓量流入都没有帮助，持仓量"流出"反而更好一些（跟直觉相反，很可能是偶然）。
- 资金费率只有 3 个月数据，笔数太少，看不出结论。
- 同级别分解五段全部亏损。做差价仍然略减收益。
- 组合（最多 5 组、每组 1% 风险）各段收益都在 ±几个百分点以内。
