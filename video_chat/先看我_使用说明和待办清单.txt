一、这个包里有什么
----------------------------------------------------------------

  video_chat\一键启动.bat   双击就能在电脑上运行（Windows）
  video_chat\app\          App 的页面（手机网页，装成 App 后也是它）
  video_chat\app\admin.html 管理后台页面
  video_chat\server\       后端服务器程序
  video_chat\mobile\       安卓 / 苹果 App 工程
  video_chat\download\     App 下载页
  video_chat\deploy\       部署到云服务器用的配置
  video_chat\e2e_preview\  我测试时的截图（可以先看看长什么样）
  video_chat\e2e_preview2\ 新功能的测试截图
  video_chat\README.md     给程序员看的技术文档

已经做好的功能：
  - 登录注册（手机验证码）、个人资料、相册、标签
  - 发现页（推荐 / 广场 / 活跃 / 附近、筛选、排行榜）
  - 一对一视频通话、语音通话，按分钟扣金币，余额不足自动挂断
  - 聊天：文字、图片、语音消息（按住说话）、送礼物
  - 社区：动态、小视频、点赞、评论、关注
  - 充值、钱包、VIP、签到、分享、邀请好友返现
  - 视频认证、实名认证、主播开通接听收费、收益提现
  - 游戏陪玩：技能、下单、接单、完成、退款申诉、评价
  - 美颜（对方也能看到）、免打扰、隐私设置、黑名单、举报
  - 离线来电和消息提醒（推送）
  - 简体 / 繁體 / English 三种语言
  - 管理后台：审核、举报、提现打款、客服回复、封号

二、在自己电脑上跑起来
----------------------------------------------------------------

1. 安装 Python（只需要一次）
   打开 https://www.python.org/downloads/ 下载安装 3.10 或以上版本。
   安装第一个界面一定要勾选 “Add Python to PATH”。

2. 解压这个压缩包，比如解压到 D:\SeeU

3. 进入 D:\SeeU\video_chat，双击「一键启动.bat」
   - 第一次会安装依赖，要等一两分钟
   - 成功后会自动打开两个浏览器窗口：
       普通窗口 = 你（用户 A）
       无痕窗口 = 测试主播（用户 B）
   - 黑色窗口不要关，关了就停止了

4. 登录方法（两个窗口一样）
   - 填手机号 → 点「获取验证码」（本地测试会自动填好）
   - 勾选同意协议 → 点「登录 / 注册」
   - 普通窗口：手机号随便填，例如 13800000001
   - 无痕窗口：填 19900000000（测试主播·小雨，已经认证、已开通接听）
   - 还有 5 个测试主播：19900000001 ～ 19900000005

5. 管理后台
   浏览器打开 http://127.0.0.1:8000/admin.html
   密码：admin123（只在你电脑上测试时用）

6. 想清空所有数据重新测
   关掉黑色窗口 → 删除 video_chat\server\seeu.db → 再双击启动

四、让朋友用起来（大约一天）
----------------------------------------------------------------
目标：朋友在手机上装安卓 App 或打开网址，就能互相视频。

1. 买一台云服务器
   - 阿里云或腾讯云，选「香港」节点（不用备案，当天能用）
   - 配置：2 核 4G 就够；系统选 Ubuntu 22.04
   - 记下服务器的公网 IP

2. 买一个域名，添加一条解析记录：
   记录类型 A，主机记录填 @，记录值填服务器 IP
   （用香港服务器不需要备案）

3. 在服务器安全组（防火墙）放行这些端口：
   80、443、3478（TCP 和 UDP 都要）、49160-49200（UDP）

4. 部署（以下命令在服务器上执行，我可以一步步带你）
   - 安装 Docker：curl -fsSL https://get.docker.com | sh
   - 把这个压缩包传到服务器上并解压
   - cd SeeU/video_chat/deploy
   - cp .env.example .env，然后编辑 .env：
       DOMAIN = 你的域名
       PUBLIC_IP = 服务器 IP
       SEEU_SECRET、SEEU_ADMIN_TOKEN、DB_PASSWORD、SEEU_TURN_PASS
         改成你自己的随机密码（越长越好，不要告诉别人）
       SEEU_PUBLIC_URL = https://你的域名
   - docker compose up -d --build
   - 手机浏览器打开 https://你的域名 ，能看到登录页就成功了

   ★ 重要：还没开通短信时，朋友收不到验证码，登录不了。
     朋友内测期间可以把 .env 里的 SEEU_DEV 改成 1，验证码会直接显示在页面上。
     但这样任何人都能用任何手机号登录，只能给熟人小范围测试，
     正式对外之前必须改回 0，并开通短信。

5. 安卓 App
   把域名告诉我，我帮你打包 APK，放到 https://你的域名/download/
   朋友手机打开这个网址就能下载安装。

6. 苹果手机（暂时）
   用 Safari 打开 https://你的域名 → 点底部「分享」→「添加到主屏幕」
   桌面上就有 SeeU 图标，用起来和 App 差不多。
   （iOS 16.4 以上，从桌面图标打开后，还能开启来电提醒）

7. 管理后台
   https://你的域名/admin.html ，密码是你在 .env 里设的 SEEU_ADMIN_TOKEN

六、常见问题
----------------------------------------------------------------

问：双击一键启动.bat 一闪就没了，或者报错？
答：把黑色窗口最后几行截图发我。最常见的原因是 Python 没装好，
    或者安装时没勾选 “Add Python to PATH”。

问：提示 8000 端口被占用？
答：之前的黑色窗口还开着，先把它关掉，再重新双击。

问：打视频看不到画面？
答：浏览器地址栏左边点锁形图标 → 允许摄像头和麦克风。
    同一台电脑两个窗口可能抢摄像头，换两台电脑测试。

问：手机连同一个 WiFi，打开我电脑的 IP 能视频吗？
答：页面能打开，但浏览器只在 https 网址下才允许用摄像头，
    所以只能文字聊天。要用手机视频，需要部署到服务器（第四部分）。

问：数据存在哪？
答：本地测试存在 video_chat\server\seeu.db，上传的图片在 video_chat\server\uploads。
    部署到服务器后存在服务器的数据库里。

问：主播收益怎么算？
答：视频 / 语音通话和礼物，主播拿 50%；陪玩订单，陪玩师拿 80%。
    这些比例可以改，告诉我想要多少就行。

问：金币和人民币怎么换算？
答：1 元 = 10 金币。充值档位和赠送数量都可以改。
