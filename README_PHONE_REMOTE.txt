# ALPHA-X 手机远程访问（稳定版）

## 最简单用法

1. 先解压整个 ZIP，不要只复制一个 BAT。
2. 在解压后的文件夹里双击 `START_PHONE_REMOTE.bat`。
3. 第一次启动会检查/安装 Python 依赖，并自动准备手机远程组件。
4. 黑窗口会一直保持，不会因为启动失败而一闪而过。
5. 成功后会显示：
   - 手机网址（https://...trycloudflare.com）
   - 手机访问密钥
   - 已复制好的完整访问地址
6. 用 iPhone Safari 打开完整地址即可。
7. **电脑上的后端窗口和“手机远程通道”窗口都不要关闭**，否则手机访问会断开。

## 如果失败

不要重复猜。

把 `START_PHONE_REMOTE.bat` 黑窗口最后 10-20 行文字截图/复制给我。
同时如果提示 Cloudflare 问题，把 `remote_tunnel.log` 发给我。

## 安全

- 远程访问默认使用随机生成的访问密钥。
- 密钥保存在本机 `.env`，不会写入代码。
- URL 中的 `#key=...` 只用于浏览器端自动填入密钥，服务器不会收到 URL fragment。
- 不要把 OKX Secret Key / Passphrase 发给任何人。
- 远程访问是公开互联网通道，只应在你信任的设备上使用。
- `888888` 保留在原系统配置中，没有删除。

## 注意

本包已经做了本地静态检查，但无法在当前环境替你实际连接 Windows + Cloudflare + 你的 OKX 网络。
