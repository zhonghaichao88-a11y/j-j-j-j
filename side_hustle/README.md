# 办公自动化接单项目

不用本金、不靠行情：用 Python 帮别人处理 Excel / PDF / Word / 图片 / 文件改名这些重复工作，按单收费。
这类需求在闲鱼、小红书、QQ/微信群里一直都有，客户多是文员、财务、HR、老师、小店主、学生会。
他们手工要干一下午，用这里的脚本通常几分钟就跑完。

## 一、工具箱里有什么（都带测试，`pytest tests` 全部通过）

| 脚本 | 能接的单 | 示例命令 |
|---|---|---|
| `excel_tools merge` | 几十上百个 Excel/CSV（含多工作表）合并成一张表，自动标注来源；兼容 GBK 编码的 CSV | `python -m office_toolkit.excel_tools merge 客户文件夹 合并结果.xlsx` |
| `excel_tools split` | 一张总表按"部门/班级/门店"拆成多个文件或多个工作表 | `python -m office_toolkit.excel_tools split 总表.xlsx 部门 输出 --one-file` |
| `word_merge` | 用 Excel 批量生成合同、证书、通知书、工资条（模板里写 `{{姓名}}`），页眉页脚和表格里的字段也能替换 | `python -m office_toolkit.word_merge 模板.docx 名单.xlsx 输出 --name-field 姓名` |
| `pdf_tools` | PDF 合并、拆成单页、提取指定页（如 `1-3,5,8-`）、提取文字 | `python -m office_toolkit.pdf_tools merge 结果.pdf 文件夹` |
| `image_tools` | 批量压缩（上传报名系统常卡大小）、缩放、转 jpg/webp、加文字水印；自动修正手机照片方向 | `python -m office_toolkit.image_tools 照片 输出 --max-side 1600 --watermark "某某店"` |
| `rename_tools` | 按 Excel 对照表或"前缀+序号"批量改名；**默认只预览**，加 `--apply` 才执行，并留下改名记录 | `python -m office_toolkit.rename_tools map 照片 对照表.xlsx` |

安装：`pip install -r requirements.txt`（在 `side_hustle` 目录下运行命令）。

## 二、怎么开始接单（第一周就能做）

1. **闲鱼发 3~5 个商品**，每个商品对应一类需求，别只发一个"什么都能做"。标题要带客户会搜的词，例如：
   - `Excel多表合并 批量汇总 几百个表格一键合并 当天交付`
   - `Word批量生成 合同 证书 奖状 工资条 邮件合并 Excel导入`
   - `PDF合并拆分 提取页面 批量处理`
   - `照片批量压缩 改尺寸 加水印 报名照片压缩到指定大小`
   - `文件批量重命名 按名单改名 学生作业照片整理`
2. **商品描述模板**（照着改）：
   > 专业做办公重复劳动的批量处理。把文件和要求发我，先免费看能不能做、报价，确认后再拍。
   > 一般当天交付，不满意免费改到满意。文件处理完即删除，不外传。
   > 不接：作业/论文代写、刷单、爬取个人信息、破解软件。
3. 同样的帖子可以发小红书（配一张"处理前 300 个表格 → 处理后 1 张表"的截图）。
4. 先用低价攒评价，有 5~10 个好评后再按正常价收。

## 三、报价参考（自己按市场调整）

| 需求 | 建议价 |
|---|---|
| 简单合并/拆分/改名/压缩（标准脚本直接跑） | 10–30 元 |
| Word 批量生成（要先帮客户整理模板和数据） | 30–100 元 |
| 需要改脚本的定制需求（特殊格式、清洗数据、多步流程） | 50–300 元 |
| 给客户做一个能自己重复用的小工具（打包成 exe 或写好使用说明） | 100–500 元 |

这些是起步价位的经验区间，不是保证收入。小单价格低，赚钱靠的是单量和复购——
同一个财务每个月都要合并报表，做熟了就是固定客户。客户问"能不能做成我自己能用的"，就是升级成定制单的机会。

## 四、交付流程

1. 先要**样例文件**和**期望结果的截图/描述**，确认需求再报价。
2. 用样例先跑一遍，把结果截图给客户确认，再处理全部文件。
3. 交付后提醒客户核对；改名之类不可逆操作，先在副本上做（`rename_tools` 本身也会先预览）。
4. 完成后删除客户文件。合同、工资条等含个人信息，不要留存、不要外传。

## 五、红线

- 不接作业、论文、考试代做；不做刷单、薅羊毛脚本；不爬取别人的个人信息；不破解软件。
  这些要么违法、要么违反平台规则，封号后之前攒的评价全白费。
- 收款走平台担保交易，不要先垫钱、不要扫陌生人的码。"先交押金/保证金才能接单"的都是骗局。

## 六、下一步可以扩展的

接到的单子里重复出现、但工具箱没有的需求，就写成新脚本放进 `office_toolkit/`，再补一个测试。
常见的候选：Excel 去重和数据清洗、图片转 PDF、Word 转 PDF（需要装 LibreOffice）、扫描件 OCR。
