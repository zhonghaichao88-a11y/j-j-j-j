# 抖音「口算挑战」号：起号说明

## 你每天要做的事（10 分钟）

1. 打开 `成品视频` 文件夹，把当天那期 `.mp4` 传到手机（微信文件传输助手就行）。
2. 抖音发布，标题和话题直接复制同名 `.txt` 里的内容。
3. **发布前一定要在「高级设置/添加声明」里选「内容由AI生成」**，因为配音是 AI 合成的。不标注会被限流。
4. 发完回复前几条评论，例如"宝贝真棒！"。评论越多，视频越容易被推荐。

我已经生成好了一年级上册和二年级上册各 7 期，够发两周（一天一个年级，或者一天两条都发）。

## 视频用完了怎么办

在电脑上双击 `一键生成一周视频.bat`，输入年级和起始期数，比如 `二年级上册`、`8`，就会生成第 8–14 期。
每一期的题目都不一样，不会重复。

第一次用之前需要装两个东西（只装一次）：
- **Python**：到 python.org 下载安装，安装时勾选 "Add Python to PATH"。
- **ffmpeg**：在命令行运行 `winget install ffmpeg`，或者到 ffmpeg.org 下载。

装不上的话，把报错截图发给我。

## 起号节奏（要有心理准备）

- **前 2–4 周**：每天坚持发 1–2 条。播放量几百是正常的，不要因为播放少就换内容，平台需要时间判断你的账号是做什么的。
- **看数据调整**：在抖音创作者中心看哪个年级、哪种题型播放高，就多做那种。也可以试试把每题秒数改成 3 秒（`--seconds 3`），做成"极速挑战"。
- **开学季、寒暑假前**是家长最焦虑的时候，那时候要多发。

## 怎么赚钱（按顺序来）

1. **商品橱窗带货**：粉丝达到抖音要求后，开通商品橱窗（门槛以创作者中心当时的规定为准），挂口算本、练习册、文具、学习桌。观众都是家长，转化比泛娱乐号好。
2. **卖自己的口算题 PDF**：`../products/成品/口算题/` 里已经做好了 5 册带答案的 30 天口算，可以在主页引导家长去闲鱼购买，或者作为粉丝福利吸引关注。
3. **接广告**：粉丝多了以后，会有教育类品牌通过星图平台找你投放。

## 不要做的事

- 不要买粉、刷量，被识别后账号会直接废掉。
- 不要搬运别人的视频。
- 不要在视频里承诺"提分""保过"。
- 不要用热门歌曲当背景音乐上传（有版权问题），要配乐就在抖音发布页里选它自带的音乐。
