# 抖音小说推文：全自动运营说明

## 它会自动做什么

```
你放进一本授权小说的正文
   ↓ 自动切成一集一集（每集约 1 分钟）
   ↓ 自动配音 + 大字幕 + 结尾「番茄小说搜 XXX」
   ↓ 自动上传抖音，每天 12:00 和 19:00 定时发布
   ↓ 自动带话题、自动勾选「内容由AI生成」
每周日 20:00 自动把下一周排满（电脑开着就行）
```

示例效果：`小说推文/成品视频/示例_不要发布_第01集.mp4`（文字是我编的，**不要发**）。

---

## 第一步：申请小说授权（免费，约 10 分钟）

1. 电脑浏览器打开 **番茄达人中心**：https://kol.fanqieopen.com/page/task ，用抖音扫码登录并绑定账号，按提示完成实名。
2. 在书库挑一本书。新手优先选**已经在推的热门书、女频情感/都市逆袭类**，开头三章最抓人的那种。
3. 点「别名推广」申请关键词，**建议直接选系统推荐的别名**（自己编的通过率低）。
4. 在「申请记录」里看到审核通过后，记下这个关键词。
5. **正规授权全部免费。** 任何人找你收"授权费""加盟费""保证金"，都是骗子。

## 第二步：把书放进来（每本书 1 分钟）

在 `小说推文/素材/` 里新建一个文本文件，文件名就是书名，比如 `离婚后她成了首富.txt`，内容照这个格式写：

```
关键词：你申请到的关键词
钩子：一句最抓人的话（可不写）
话题：都市小说,逆袭（可不写）
---
从推广后台复制的小说正文（前几章就行，越多集数越多）
```

大约每 380 字切成一集。复制 1 万字，能出 20 多集，够发 10 天以上。

## 第三步：一次性设置（只做一次）

在 Windows 电脑上按顺序双击：

1. `安装自动发布.bat`：电脑上要先装好 Python，安装时勾选 "Add Python to PATH"。
2. `登录抖音.bat`：用手机抖音扫码登录。
3. `立即排期一周.bat`：马上生成视频并排好未来 7 天。
4. `设置每周自动运行.bat`：以后每周日晚上自动排下一周。

## 平时要做的（每周 5 分钟左右）

- **回填发文**：番茄达人中心要求把发出去的视频链接填回「申请记录 → 回填发文」，佣金才好对上。在抖音里复制作品链接，粘贴过去就行。（这一步要登录番茄后台，没法替你自动做。）
- **补书**：日志里提示"存货不到一周"时，往 `素材/` 再放一本。
- **看收益**：番茄达人中心能看到每本书的收益。哪本赚钱就多切几章，不赚的换书。
- **出错时**：打开 `发布日志.txt` 看原因。一般是登录过期，重新双击 `登录抖音.bat` 扫码，再双击 `立即排期一周.bat`。

## 额外收入：创作者伙伴计划（申请一次就行）

抖音 App → 创作者中心 → 创作变现 → 找「创作者伙伴计划」（或「中视频计划」）申请。通过后，同样这些视频的播放量也能分钱。AI 内容能不能拿到这笔收益，平台没有写明，申请了不亏。

## 蹭活动话题

在创作者中心「创作灵感 → 官方活动」看到和小说相关的话题时，用记事本打开 `auto_publish.py`，找到这一行：

```
ACTIVITY_TAGS = []
```

改成 `ACTIVITY_TAGS = ["话题名"]`，保存。以后每条作品都会自动带上这个话题。

## 风险，务必知道

- 自动上传用的是开源工具 social-auto-upload，它模拟人在网页上操作。抖音规则不允许第三方工具自动操作，**有被限流或封号的可能**。抖音网页改版后，工具可能暂时失灵，要等作者更新。
- 只发**你拿到授权的书**。用没授权的小说会被举报侵权。
- 不保证收益。做小说推文的人很多，赚多少主要看选书，前两周没什么收益很正常。
