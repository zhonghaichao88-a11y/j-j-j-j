ALPHA-X 手机远程访问

最简单的使用方法：
1. 在家里的 Windows 电脑上，先双击“启动 ALPHA-X.bat”。
2. 再双击“START_PHONE_REMOTE.bat”。
3. 等窗口出现 https://xxxx.trycloudflare.com 地址。
4. iPhone 打开 Safari，输入这个地址。
5. 第一次进入 ALPHA-X 页面后，点击“设置系统访问密钥”，输入启动窗口显示的“手机访问密钥”。
6. 以后手机和电脑可以同时使用同一套 ALPHA-X。

重要：
- 家里的电脑和 ALPHA-X 后端必须保持运行。
- 关闭远程访问窗口会断开手机远程访问，但不会自动修改交易策略。
- 手机访问密钥不是 OKX API 密钥，不要和 OKX Secret Key/Passphrase 混用。
- 不需要在手机或电脑输入 Python、命令行或内部指令。
