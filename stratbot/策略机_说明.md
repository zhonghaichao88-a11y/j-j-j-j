# 策略机：开源策略独立运行程序

**不用装 freqtrade，也不用别的网站。** 把 GitHub 上的开源策略原文件放进来，由本程序自己拉欧易行情、算信号、下单，自带网页。

## 一、怎么启动

1. 电脑上要有 Python 3.10 以上（和订单流一样）。
2. 解压后双击 **`START_策略机.bat`**。
   - 第一次会自动建运行环境、装依赖（pandas、TA-Lib 等），要几分钟，别关黑窗口。
   - 然后会问代理地址，和订单流 / V7 的 PROXY_URL 一样（比如 `http://127.0.0.1:7890`）；不用代理就直接回车。
   - 接着问欧易 API。只用模拟盘就直接回车跳过。
3. 准备好后浏览器会自动打开 **http://127.0.0.1:8020**。第一次要下载约 94 个币的历史 K 线，2~3 分钟，网页上有进度条。
4. 黑窗口别关，关了程序就停了。

## 二、网页上有什么

- **成绩**：今天、最近 7 天、全部的单数、胜率、盈亏比、盈亏。模拟盘和实盘分开算。
- **持仓**：开仓价、现价、盈亏、拿了多久、止损价（"移动中"表示移动止盈已经启动）、离到点平仓还有多久。每单都有"平仓"按钮。
- **策略**：
  - 勾选就开始跑。
  - 能改"本金"和"最多同时几单"，每单资金约等于本金 ÷ 单数。
  - 写着这个策略的出场规则，点开能看回测成绩（每年的单数、胜率、盈亏比、回撤）。
- **最近信号和开平仓**：开了什么、平了什么、为什么没开（比如开满了、钱不够最小下单）。
- **历史成交**：每一单的明细。
- **设置**：
  - 当天亏损上限：超过就当天不再开新单。默认 0 = 不限制，和回测一样。
  - 选币：回测用的那批币，或欧易全部 USDT 合约。
- **暂停开新单**：已有的仓位照常按规则平，只是不开新的。

## 三、模拟盘和实盘

- **默认是模拟盘**：按欧易实时价格模拟成交，扣吃单手续费 0.05% + 滑点 0.02%（每边），不动你的账户。
- **切换实盘**：
  1. `.env` 里 `SB_ALLOW_LIVE=1`，填好 API，然后重启。
  2. 网页上点"切换到实盘"，输入确认口令"我确认开实盘"。
  3. 切换前当前模式不能有持仓。
- **实盘怎么下单**：
  - 市价开多，1 倍杠杆、逐仓。
  - 开仓时在欧易挂一张**保护止损**，比策略止损再远 1%（ElliotV8 是 -21%）；策略止损很宽的（E0V1E_DCA3 是 -99%）按最多亏 80% 挂。程序关了也有它兜底。
  - 会加仓的策略：补仓用市价单，补完撤掉旧的保护止损，按新的总张数和新均价重新挂；分批平仓同样处理。
  - 有持仓的币订阅欧易的实时价格推送，价格一变就检查要不要平；推送断了，还有每 2 秒查一次价格兜底。
  - 按策略规则平仓用市价单。
  - 平仓后从欧易读真实盈亏，含手续费和资金费。
- **重启后自动对账**：
  - 程序记着的仓位，如果欧易上已经没了（比如保护止损触发、你在 App 里平了），会记成"交易所已平"，用欧易的真实盈亏记账。
  - 欧易上不是本程序开的仓，程序不会动，也不会再开这些币。
- **建议**：用子账户 API，只给"交易"权限，不给"提币"。

## 四、现在收录的策略

| 策略 | 来源 | 做法 |
|---|---|---|
| ElliotV8（均线下方抄底，快进快出） | GitHub jilv220/freqtrade-stuff，原文件一行没改 | 只做多，5 分钟 K 线。跌到均线下方、RSI 低时买。赚 2% 后回落 0.1% 就走；卖出信号出现且赚超过 1% 也走；最多拿 200 分钟到点就平；止损 -20% |
| E0V1E_DCA3（超跌抄底 + 跌多了补一次仓） | GitHub TheoBrigitte/freqtrade，原文件一行没改 | 只做多，5 分钟 K 线。明显低于均线、RSI/CTI 超卖时买，先用 65% 的资金；亏到 5% 以上补剩下的 35%，最多两笔。有盈利且指标冲高时把止损收紧到当前价下方 0.1%；长时间不动、量缩时止损出场。默认不勾选，建议先模拟盘 |

E0V1E_DCA3 的成绩：freqtrade 在欧易 137 个币上 2021~2026 每年盈亏比 1.48~2.83；币安全部约 900 个币每年 1.43~2.73。
但它的回测偏乐观：用 1 分钟 K 线细算，收益约打六五折（盈亏比 3.57 → 2.53，2022 年一季度 15 个币）。所以默认不勾选，先模拟盘看实际成交。

以后找到别的好策略，把 `.py` 文件放进 `strategies` 文件夹，在 `sb_config.default.json` 里加一行就能用。

支持的 freqtrade 功能：自定义止损、自定义平仓、开仓/平仓前确认、**加仓和分批平仓**、**策略自己定每单资金**、**别的周期或别的币的 K 线**（informative_pairs / @informative）、每轮开始回调（bot_loop_start）。
用到下面这些功能的策略，程序会拒绝加载，宁可不跑，也不能跑出和回测不一样的结果：

- 做空
- 自定义进场价 / 平仓价、挂单超时处理、订单成交回调
- 实盘/模拟盘只跑 5 分钟 K 线的策略（回测引擎各种周期都支持）

## 五、和 freqtrade 回测对过账

`orderflow/分析/开源策略/parity_stratbot.py` 用同样的 K 线、同样的币，把本程序的回测引擎和 freqtrade 回测逐单对比：开仓时间、平仓时间、平仓原因、收益率，四项都要一样。

`replay_stratbot.py` 把历史 K 线当实时行情，喂给本程序**真正跑的代码**（开仓、平仓、记账），再和 freqtrade 对比。

结果见网页上每个策略的"回测成绩"，以及 `开源策略/策略机核对结果.md`。

## 六、文件说明

| 文件 | 作用 |
|---|---|
| `START_策略机.bat` | 双击启动 |
| `launch_sb.py` | 启动脚本（第一次问 API、等网页就绪后打开浏览器） |
| `sb_app.py` | 网页服务 |
| `sb_bot.py` | 主程序：行情、开仓、平仓、记账、实盘对账 |
| `sb_engine.py` | 出场规则（止损、移动止盈、ROI、卖出信号），照 freqtrade 代码搬的；回测和实盘共用 |
| `sb_loader.py` | 加载 freqtrade 写的策略文件（假的 freqtrade 接口，策略文件不用改） |
| `sb_data.py` | 欧易公开行情 |
| `sb_live.py` | 欧易实盘下单，和订单流同一份代码 |
| `sb_notify.py` | 手机推送（可选） |
| `strategies/` | 策略原文件 |
| `sb_config.default.json` | 默认设置。你改过的设置存在 `sb_config.json`，升级不会覆盖 |
| `sb_backtest.json` | 网页上显示的回测成绩 |
| `.env` | 你的 API 和代理（不要发给别人） |
| `sb_state.json` / `sb_trades.jsonl` | 持仓和成交记录（程序自动写） |
