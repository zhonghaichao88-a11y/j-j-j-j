# 订单流看盘 + 自动交易（欧易永续）

## 能做什么
- **足迹图**：每根K线拆到每个价位，左边数字是主动卖，右边是主动买。颜色越深成交越大，紫色格是这根K线成交最多的价位。下面方框里是 Delta 和总量。
- **斜向失衡**：粗体绿字是买方失衡（主动买 ≥ 下一格主动卖的 3 倍），粗体红字是卖方失衡。连续 3 格算堆叠失衡，会画成绿色或红色的横带。
- **成交量分布**（价格轴左边）：金色是 POC（成交最多的价），蓝色是价值区（70% 成交量所在的区间）。虚线是前一天的 POC、VAH、VAL。
- **挂单深度**（最右边）：左边是买单，右边是卖单。黄色的是大单墙，挂单量 ≥ 平均的 3 倍。
- **6 种订单流打法自动识别**，图上用三角形标出来：堆叠失衡回踩、吸收、衰竭、Delta 背离、被套反向、价值区回归。
- **自动交易**：勾选打法，再打开总开关。每单都带止损止盈，并且有风控：
  - 每单最多亏权益的 0.5%
  - 杠杆上限
  - 同时持仓数上限
  - 单日亏损到线自动停止开新单
- **默认是模拟盘**。实盘要同时满足三个条件：`.env` 里写 `OF_ALLOW_LIVE=1`、填好 API 密钥、网页上输入确认口令"我确认实盘"。

## 怎么用
1. 把 `.env.example` 复制成 `.env`，在 `PROXY_URL` 填你的代理地址（和 V7 一样）。
2. 双击 `START_ORDERFLOW.bat`，浏览器会自动打开 http://127.0.0.1:8010
3. 鼠标滚轮可以上下移动价格，按住 Shift 再滚轮可以左右翻K线，拖动也可以。右上角的 ＋/− 用来缩放。

## 回测结果（必须看）
数据用的是欧易官方逐笔成交，BTC、ETH、SOL 永续，2026-04-01 到 2026-09-29，共 6 个月。
测法：K线收盘才判断，下一根开盘进场；止损止盈按每分钟的最高价、最低价检查，同一分钟两个都碰到算先止损。
手续费按吃单 0.05%，滑点 0.02%。

三个币合计的 PF（大于 1 才赚钱）：

| 打法 | 5分钟 | 15分钟 | 1小时 |
|---|---|---|---|
| 堆叠失衡回踩 | 0.27 | 0.39 | 0.32 |
| 吸收 | 0.51 | 0.75 | 0.65 |
| 衰竭 | 0.47 | 0.64 | 0.83 |
| Delta背离 | 0.43 | 0.63 | 0.70 |
| 被套反向 | 0.50 | 0.43 | - |
| 价值区回归 | 0.59 | 0.67 | 0.85 |

另外测了两种情况：
- **改成挂单手续费**（0.02%，不算滑点）：BTC 还是全部小于 1。
- **反着做**（信号说多就做空）：也是亏。

**结论：这些形态按通用规则自动执行，扣掉成本后都不赚钱，连扣费前也只是接近打平。**
看订单流的人一般是"看图 + 主观判断"。这个工具可以当看盘工具用，**自动交易先别开，尤其别开实盘。**
每种打法的详细数据在 `回测结果/` 文件夹里。

## 文件
| 文件 | 作用 |
|---|---|
| `of_core.py` | 足迹K线、失衡、成交量分布、6 种形态识别（回测和实盘共用） |
| `of_feed.py` | 欧易行情：WebSocket 优先，连不上自动改 REST 轮询；启动时补最近几根足迹 |
| `of_engine.py` | 下单、风控、模拟盘、实盘（ccxt，开仓同时在交易所挂好止损止盈） |
| `of_app.py` | 网页服务器 |
| `static/of.html` | 看盘界面 |
| `fetch_fp.py` | 下载欧易历史逐笔成交，压成足迹数据 |
| `of_backtest.py` | 回测 |
| `of_make_result.py` | 生成网页上显示的回测成绩 |
