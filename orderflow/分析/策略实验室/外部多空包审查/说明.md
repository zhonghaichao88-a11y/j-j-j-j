# 多空策略包复查：按正确口径重算

## 怎么跑
1. 把 `ls_check.py` 放在你项目根目录（有 `data/k/币.parquet` 的那一层，和 `strat_pkg` 同级或任意位置都行）。
2. 在项目根目录运行：`python ls_check.py strat_pkg`（参数是包含 `strategies/` 文件夹的那个目录）。
3. 它会用你包里的 `load_symbol`、`compute_ind`、`gen_signals` 原样出信号，进出场逻辑和 `backtest_long` / `short_strategy` 一模一样，
   只是每笔多记两样东西：**加仓后的实际仓位** 和 **每一笔进出（包括加仓）的手续费**。

## 对比的两种口径
- 原口径（报告用的）：`pnl_u = ret_pct/100 × 4U`，`win = ret > 0`。ret 是相对均价的价格涨跌——**没扣手续费，也不管加了几份仓**。
- 正确口径：`盈亏 = 实际仓位 × (平仓价 − 均价) − 全部手续费`（第一笔 4U，每次加仓 +2U，费率 fee+slip=0.0008 每边），胜负也按扣费后算。

## 我这边的结果（币安 5 分钟K线合成 1 小时，17 个币，参数用报告里的最优参数）
2022 年原口径和报告完全一致（多头 15060 笔 / 66.3% / +209.3U；空头 2260 笔 / 73.3% / +39.8U），说明数据和逻辑都对上了。

| 策略 | 年份 | 原口径 | 正确口径 |
|---|---|---|---|
| 多头 D（rsi45/tp3%/hold144/DCA 1.5,3,5%） | 2022 | 66.3% / +209.3U | 胜率 61.4%，PF 0.75，−163.9U |
| | 2023 | 66.5% / +181.5U | 59.0%，PF 0.89，−40.3U |
| | 2024 | 68.3% / +202.4U | 62.5%，PF 0.89，−44.8U |
| | 2025 | 67.7% / +162.0U | 61.9%，PF 0.76，−110.7U |
| 空头（rsi70/exit35/tp5%/hold144/DCA 1.5,3,5%） | 2022 | 73.3% / +39.8U | 66.4%，PF 0.97，−2.2U |
| | 2023 | 71.8% / +27.7U | 62.9%，PF 0.75，−17.3U |
| | 2024 | 70.6% / +25.1U | 63.5%，PF 0.78，−13.6U |
| | 2025 | 73.3% / +24.2U | 65.7%，PF 0.79，−11.0U |

加过仓的单占 20~30%，按实际仓位算，这部分每年多头亏 270~520U、空头亏 40~50U——"DCA 是盈利发动机"的结论是因为没乘仓位造成的，实际正好相反。

## 另外几点
- 止损只看 1 小时收盘价，K线中间穿过 −8% 不算，实盘亏损会更大；没算资金费。
- 打分用"胜率×0.5 + 收益×0.5"做网格搜索，rsi45 是看过结果后在网格外加的，有挑参数的成分。
